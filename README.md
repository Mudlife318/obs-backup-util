# obs-baackup-util
obs backup utility
Download Python 3.6 (most should already be using it for the Rust Map Hider)  > https://www.python.org/ftp/python/3.6.2/python-3.6.2-amd64.exe 

Install OBS_Backups_v1.py
Select the folder you would like the exports saved in (I recommend using a NAS or mapped cloud folder, in case your machine is unrecoverable)
Backups will be stored in the selected folder, in a Timestamped folder. i.e. "backup_2024-09-15_14-06-35"
Select Your backup Interval
Select Your Retention Period
Select "Enable Automatic Backups"

There is also the functionality to Manually backup your data if needed by clicking "Export Profiles and Scenes"
